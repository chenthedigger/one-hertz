## Design-gate calls made this lane

1. **Opaque plate over scene-graph hiding.** The source hides the watch mesh; ours covers with the ground-token plate instead — zero cross-lane scene-graph writes, works during partial traversal (a mesh-visibility toggle would pop while the plate only half-covers a 100svh track), and inherits bgStage ramps for free.
2. **Kept the frozen 100svh budget (no bump).** Motion bible §8 flags Images source at 201vh ⚠ with a sanctioned-bump escape hatch; the grammar FITS 100svh — the rise beats live in the 200vh traversal window and the whole sheet composes as one editorial spread. No shared-constant edit.
3. **Crops art-directed in CSS:** fig 05 `object-position 50% 35%` lifts the engraved WATCH ULTRA arc into the wide cell; fig 02 nudged toward the crown. The masters are the council's canonical frames — cover-crop + position, never re-renders.

## Pitfalls found this lane (inherit)

1. **Concurrent lanes break the shared build gate transiently** — `tsc` failed on another lane's in-flight file mid-session. Iterate visually on a private `vite` dev port, run the official build+preview gates when the tree settles, and kill your dev server after (only :4573 is shared).
2. **Gallery images must be `loading="eager"` + decoded before capture** — lazy stills inside a `gotoSection`-jumped viewport race the screenshot; the proof script awaits `img.decode()` on all stills (pattern: scratchpad `images-proof.mjs`).
3. `new Image()` preflight probes resolve out of order under rapid swaps — guard with a latest-request token or a stale set wins.
4. An unpinned 100svh plate covers the full viewport only at p≈0.5 — anything meant to be photographed "complete" must be settled well before .5, not by the traversal end.
